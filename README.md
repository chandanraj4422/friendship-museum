# Friendship Museum (MVP) 🎀

A serverless, client-side digital gifting experience. This project allows users to create a personalized digital "museum" for their friends and share it instantly via a dynamically generated URL fragment.

## 🚀 Features
- **Zero Backend:** Runs entirely on the client side using DOM manipulation and URL hash encoding (`#draft=...`).
- **Logic Bypass:** Custom client-side logic to bypass heavy, obfuscated third-party payment scripts for a seamless MVP experience.
- **Instant Sharing:** No database required. The link itself carries the payload to reconstruct the DOM on the receiver's end.

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
